### Earlier attempts from the build box (before the droplet)

The build box has HTTP(S)-proxy-only egress, so no account-free tunnel could be opened from it:

| Option | Account needed | Result from the build box |
|---|---|---|
| Cloudflare quick tunnel (`cloudflared tunnel --url`, trycloudflare.com) | none | **Fails.** Egress is HTTP(S)-proxy only. cloudflared needs QUIC/UDP or TCP 7844 to Cloudflare edge; both are blocked. |
| tunnelmole / localtunnel-style tunnels | none | **Fails.** They need raw TCP (for example 8083); blocked. |
| SSH reverse tunnels (serveo, localhost.run, pinggy) | none | **Fails.** Outbound SSH (22/443 raw) is blocked. |
| Cloudflare named tunnel / Workers | Cloudflare account | not attempted (would need an account) |
| Render free web service (`deploy/render.yaml`) | Render account + Git repo | ready, not deployed |
| Fly.io (`deploy/fly.toml`) | Fly account; may ask for a card (out of scope) | ready, not deployed |
| Vercel | Vercel account; serverless, which does not fit the background verdict/finalize loop | not recommended |

## Path 1 (no account): a quick tunnel from a machine with normal egress

On any machine that allows outbound QUIC/UDP or TCP 7844 (a normal home or office network), with this repo checked out
(`git submodule update --init`), `cd agent && npm ci`, `forge build`, and the four testnet keys present as
`.secrets/testnet-{relayer,provider,evaluator}.key` and `agent/.keys/operator.json` (or as the env vars
`AGENTCOIN_RELAYER_KEY`, `AGENTCOIN_PROVIDER_KEY`, `AGENTCOIN_EVALUATOR_KEY`, `AGENTCOIN_OPERATOR_KEY`), run:

```bash
bash deploy/quick-tunnel.sh
```

It starts the tunnel, reads the `https://<random>.trycloudflare.com` URL, re-signs the artifacts with that URL
(`AGENTCOIN_HOSTED=1`), and starts the service.

Limits: the URL is random and changes on every restart. It lives only as long as that machine and process. Cloudflare
documents quick tunnels as for testing, with no uptime guarantee.

After it is up, point the ERC-8004 registration at the hosted copy. The operator pays the gas; an https URI is far
cheaper than the current ~1.4M-gas data: URI. The `uri` phase first checks that the URL serves a registration naming
agent 10494. A quick-tunnel URL changes on every restart, so do this only for a stable host:

```bash
cd agent && AGENTCOIN_NETWORK=base-sepolia AGENTCOIN_HOSTED=1 AGENTCOIN_BASE_URL=https://agentcoin.143-244-167-51.sslip.io node scripts/sepolia-v04.mjs uri
```

Done for the droplet host: tx `0xad7c150d095570514fc0175a8d77c1ba961382daacfe2c33aae6fcd2bddaf848` (266,589 gas, 1.5995e12 wei). The operator has about 0.0000194 ETH left.

## Keys on a host

Hosting means placing the four throwaway testnet keys on that host. They control test funds only. Never reuse them on
mainnet. To rotate, generate new keys, re-run the `fund` phase from the deployer, and re-run `register` for the operator.
