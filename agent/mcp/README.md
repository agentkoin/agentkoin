# AgentCoin MCP server (stdio)

Testnet and local only. This stdio server runs as a local process. The same 5 tools are also served over streamable HTTP by the hosted testnet service at `https://<retired-sslip-host>/mcp` (see `docs/QUICKSTART-AGENTS.md` §0).
Tool definitions (names, descriptions, input/output JSON Schemas) are in `tools.manifest.base-sepolia.json`, which is a
`tools/list` dump generated by `agent/scripts/gen-mcp-manifest.mjs`.

```json
{
  "server": "agentcoin-base-sepolia",
  "version": "0.3.0",
  "transport": "stdio",
  "command": "node",
  "args": ["agent/mcp/server.mjs"],
  "cwd": "<repo root>",
  "env": { "AGENTCOIN_NETWORK": "base-sepolia" },
  "optionalEnv": { "RPC_URL": "https or loopback JSON-RPC for chain 84532; default https://sepolia.base.org" },
  "chainId": 84532,
  "hosted": false,
  "manifest": "agent/mcp/tools.manifest.base-sepolia.json",
  "tools": ["quote", "open_job", "get_job_status", "get_evaluator_reputation", "verify_attestation"]
}
```

## Launch

```bash
cd agent && npm install
AGENTCOIN_NETWORK=base-sepolia node mcp/server.mjs      # stdio; no port is opened
```

MCP client config (stdio):

```json
{ "mcpServers": { "agentcoin-base-sepolia": { "command": "node", "args": ["mcp/server.mjs"], "cwd": "<repo>/agent", "env": { "AGENTCOIN_NETWORK": "base-sepolia" } } } }
```

With `AGENTCOIN_NETWORK` unset the server targets the local Anvil deployment (`deployments/local.json`, chainId 31337).

## Tools

| Tool | Input (required in **bold**) | Effect |
|---|---|---|
| `quote` | **amount**, providerBond, evaluator | Read-only. Fees, provider net, challenge bond, arbitration fee, windows, config version, adapter bond and minimum kernel expiry; with `evaluator`, its stake and capacity. |
| `open_job` | client, **provider**, **evaluator**, **amount**, **deadlineSeconds**, spec/specHash | Builds two unsigned EIP-1559 txs: `USDC.approve(escrow, amount)` and `JobEscrow.createAndFund(...)`, with chainId 84532, nonces and calldata. Nothing is signed or sent. `demoSign` is refused on base-sepolia. |
| `get_job_status` | **jobId** | Read-only. State, outcome, payoutBps, parties, amounts, bonds, deadlines, dispute record, and the tx hash of every event. |
| `get_evaluator_reputation` | **evaluator** | Read-only. Raw counts from escrow, registry and adapter events (verdicts by outcome, disputes, overturned, missed, slashes) plus stake and tx-hash evidence. No score. |
| `verify_attestation` | **document**, expectedSigner | Read-only. Checks the signature and on-chain claims of a trust manifest, attestation, A2A card or ERC-8004 registration document. |

Conventions: amounts are USDC base units (6 decimals) as decimal strings; times are seconds; every response carries
`chainId`, `networkName` and contract addresses.

## Reads

All reads use JSON-RPC against `RPC_URL` (default `https://sepolia.base.org`). That RPC caps `eth_getLogs` at 200 blocks,
so event scans are chunked, and the results are cached in `agent/.cache/84532/` (gitignored). The first
`get_evaluator_reputation` or `get_job_status` call after a cold start can take tens of seconds.
